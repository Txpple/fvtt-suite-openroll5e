## dnd5e 6.1.0 release notes

Kept verbatim from foundryvtt/dnd5e (MIT).

<img width="2560" height="1440" alt="6.1.0 release banner showing group sheet, renown sheet, and faction sheet" src="https://github.com/user-attachments/assets/e336a8bf-52a1-4362-ac59-9d98e193c77a" />

The 6.1 release of the D&D Fifth Edition system is a smaller release that builds on the foundations laid in 6.0, putting the new ActiveEffect rules framework and Region Behaviours to work. It brings optional renown tracking with factions, a new Antimagic Region Behaviour, and new rules for ignoring or downgrading damage resistances, immunities, and vulnerabilities. We have also continued integrating newer system features with the SRD 5.2 content, with every class, subclass, and species receiving an update. As always, you can see the full list of bug fixes and improvements at the bottom.

**⚠️ COMPATIBILITY WARNING: ⚠️** The version 6.1 release of the system **ONLY SUPPORTS** Foundry Virtual Tabletop version 14 and greater.

**⚠️ IMPORTANT: ⚠️** If you previously downloaded the 6.1 *pre-release* version, you **MUST** uninstall and then re-install the game system. Failing to do so may result in corrupt or lost data.

**Installation:** To manually install this release, please use the following manifest URL: https://github.com/foundryvtt/dnd5e/releases/download/release-6.1.0/system.json

### Renown

An optional rule from the Dungeon Master's Guide allows for individuals or groups to maintain a certain level of renown with factions and organisations within the world. Increasing renown with a given faction can grant access to certain perks, like access to a special stock of weapons and equipment or services, specialised training, or even the ability to commission certain members of the faction to accompany the group for a time.

In order to simplify some of the book-keeping involved with tracking renown, the system now supports a new renown item. These items can be used to record the actions that triggered renown changes with various factions.

<img width="500" height="428" alt="Example Renown Item showing modifiers for multiple factions" src="https://github.com/user-attachments/assets/fa8edd3e-c3ce-4cc4-844e-6bf070855238" />

These renown items are visible on both character and group sheets.

<img width="700" height="705" alt="Example group sheet showing several renown tickets" src="https://github.com/user-attachments/assets/7a467d4e-b0c5-4a83-96c0-d5c908bda978" />

The factions themselves will display a summary of all the individuals or groups who have some renown with them.

<img width="500" height="320" alt="Example faction sheet showing several members" src="https://github.com/user-attachments/assets/ac9796c2-05e4-4d10-a734-116e1f62c3c8" />

If you would like to make use of this feature, you can turn it on under the 'Variant Rules' settings in the system settings.

### Antimagic

We've been slowly adding the data required to mark Items and ActiveEffects as magical, and are finally able to capitalise on it with the new Region Behaviour types introduced in v14. The system now supports an Antimagic Region Behaviour that will suppress all ActiveEffects marked as magical on creatures that enter the area, will suppress the magical bonuses on weapons and armour, and will hide any activities that cannot be activated where magic is unavailable.

<img width="500" height="501" alt="Activity configuration showing an Antimagic Region Behaviour" src="https://github.com/user-attachments/assets/c0420aaa-ba14-4c25-89ca-889ac4cf0abd" />

### Damage Rules

We've seen an uptick in the number of features that ignore damage resistance or immunity. Taking advantage of the new rules-type ActiveEffect framework introduced in 6.0, we have added a new rule type that allows for downgrading or ignoring resistances, immunities, and vulnerabilities.
